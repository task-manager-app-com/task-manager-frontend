# 📄 Task Manager Application - Frontend

This is the frontend application for the **Task Manager Application**, a platform that allows users to manage their futuer tasks. 

---

## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### ✅ Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Virtual-Pet-Adoption-Center/pet-adoption-frontend.git

# Navigate into the project directory
cd pet-adoption-frontend

# Install dependencies
npm install

# Start the development server
npm start

```

### 🛠️ Tech Stack
- React – Frontend framework
- Material UI – UI components and icons
    npm install @mui/material @emotion/react @emotion/styled
    npm install @mui/icons-material
- React Router DOM – Client-side routing
    npm install react-router-dom
- Axios – HTTP client for API requests
    npm install axios
- date-fns – Date formatting npm i date-fns

### 📌 Key Features
- View recent 5 tasks
- Add new task
- View history
- Complete a task
